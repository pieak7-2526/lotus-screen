# หน้าจอปฏิทิน Lotus's + อุณหภูมิ + PM2.5

## เปิดใช้
- **ทดลองเร็ว:** ดับเบิลคลิก `index.html` บนคอม/มือถือ (ต้องต่อเน็ตเพื่อดึงอุณหภูมิและ PM2.5)
- **ใช้กับทีวี / ติดตั้งเป็นแอป:** อัปโหลดทั้งโฟลเดอร์นี้ขึ้นเว็บฟรี เช่น Netlify Drop (app.netlify.com/drop) หรือ GitHub Pages
  แล้วเปิดลิงก์บนเครื่องนั้น → เมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอหลัก / Install app" จะเปิดแบบเต็มจอ
- Android TV / Google TV: เปิดลิงก์ด้วยเบราว์เซอร์ (เช่น TV Bro) แล้วกด "เต็มจอ"

## ปุ่มรีโมต / คีย์บอร์ด
ซ้าย/ขวา = เปลี่ยนเดือน · Home หรือ 0 = กลับวันนี้

## เพิ่มปฏิทินปีใหม่
1. คัดลอก `data/2026.js` เป็น `data/2027.js` (มีแม่แบบให้แล้ว)
2. เพิ่มกิจกรรม `{ date: "2027-01-15", end: "2027-01-20", title: "...", type: "lotus" }`
   type: holiday (แดง) · lotus (เขียวอมฟ้า) · promo (เหลือง) · store (ม่วงฟ้า)
3. ถ้าติดตั้งเป็นแอปแล้ว ให้เพิ่มชื่อไฟล์ปีใหม่ใน `sw.js` (รายการ FILES) ด้วย

## ข้อมูลอากาศ
Open-Meteo (ฟรี ไม่ต้องใช้คีย์) อัปเดตทุก 15 นาที ตั้งเมืองได้ที่ปุ่ม "ตั้งค่า" (ค่าเริ่มต้น กรุงเทพฯ)
สี PM2.5 ตามเกณฑ์กรมควบคุมมลพิษ: ≤15 ดีมาก · ≤25 ดี · ≤37.5 ปานกลาง · ≤75 เริ่มมีผล · >75 มีผลต่อสุขภาพ
